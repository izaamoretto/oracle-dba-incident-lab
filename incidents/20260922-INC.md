\# 20260922-INC — Falha de conexão com Oracle



\## Ambiente

\- Oracle Database 26ai Free

\- Docker

\- Serviço: FREEPDB1

\- Schema: APP\_VENDAS



\## Sintoma

A aplicação não consegue estabelecer novas conexões TCP com o banco de dados.



\## Erro identificado

`ORA-12541: Cannot connect. No listener at host 127.0.0.1 port 1521.`



\## Investigação

O comando `lsnrctl status` retornou `TNS-12541`, confirmando a indisponibilidade do Listener.



Uma conexão administrativa local via `sqlplus / as sysdba` permitiu verificar que a instância `FREE` permanecia `OPEN` e o banco `ACTIVE`.



\## Causa

O Oracle Listener havia sido interrompido intencionalmente para simular uma falha de conectividade no laboratório.



\## Ação corretiva

Reinicialização do Listener com o comando:



&#x20;   lsnrctl start



\## Validação

Após a inicialização do Listener, uma nova conexão TCP com o serviço `FREEPDB1` foi estabelecida com sucesso.



\## Resultado

\- Listener restaurado.

\- Conectividade TCP restabelecida.

\- Instância Oracle permaneceu disponível durante o incidente.

\- Novas conexões voltaram a funcionar.



\## Status

Resolvido
